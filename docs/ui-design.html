窗口与布局

  • 设置类界面一律 左侧导航 + 右侧内容 + 滚动，禁止把所有东西硬塞进一个框（全局约定）
  • 滚动条常显，不自动隐藏；否则用户既看不到下半部分、也不知道还能滚
  • 窗口 880 × 620 硬约束，不被内容撑宽（曾撑成 917）
  • 长文案宽度上限 616px 硬约束（只设 preferredMaxLayoutWidth 不钳制 intrinsicContentSize）
  • 按秒刷新只更新值字段，不重建视图树（否则滚动位置和开关状态被重置）
  • 六个分区：时区同步 / 菜单栏 / 启动 / 改时区方式 / 维护 / 关于
  • 左侧导航纯文字（不放图标），选中态是圆角白片 + 1px 描边；不能用 AppKit 默认的强调色通栏 —— 跟右侧圆角卡片并排就是「一格方块一格圆角」

窗口头部 / 脚部

  • 头部 104pt：应用图标 + 应用名（19pt 半粗）+ 一句话定位（12pt 灰）。只放「是什么」，不放状态
  • 脚部 54pt = 常驻状态条：左侧助手状态徽章（8px 圆点 + 文案），右侧只有「关闭」按钮
  • 状态徽章三态：绿 免授权模式已启用 · 改时区零弹窗 / 橙 助手已就位但没响应 · 可在下面重装 / 灰 免授权模式未安装 · 每次改时区会弹授权框
  • 去重：应用名只留在头部大标题；版本号与仓库 / 许可证一起进「关于」（头部、脚部都不再出现）；日志路径只留在「维护」分区
  • 窗口标准按钮（红黄绿）隐藏、标题栏透明，顶部视觉由 104pt 头部承担

状态区口径（窗口与菜单同一套）

  • 时间 = 日期 + 时刻（10月3日 周六 / 17:35:54），等宽字体、右对齐
  • 时区标识三件套：IANA 名 + 字母缩写 + UTC 偏移（America/Los_Angeles · PDT · UTC-7）
  • 时差用紧凑写法 -15h，只出现在「是否有差别」行，不散在时区行的小字里
  • 是否有差别：有 → 橙徽章 + -15h + 「回到归位时区」按钮；无 → 绿勾 + 「无」+ 一句话
  • 出口信息：IP · 地区 · IANA 名；与系统时区一致时标绿「与系统一致」
  • 长标识（IANA 名 / plist 路径 / 日志路径）降级为 11px 等宽灰字

菜单栏标题

  • 格式跟随系统自带时钟：10月3日 周六 08:18，默认不显示秒
  • 字号 13pt（实测与系统时钟墨迹宽一致：119px 对 119px）
  • 不要图标（原 ◇ 太小看不见）
  • 颜色用橙（原红色太刺眼）；与系统时区不一致时保持橙色提示

下拉菜单

  • 整体精简，主次分明：状态在最上 → 主操作加粗 → 次级功能收进「高级配置…」→ 退出
  • 总行数 ≤10（不含子菜单）；数据驱动（MRow 模型 → render()），可用 --menu 打印审查
  • 状态 3 行：东八区 / 系统时区 / 出口
  • 系统时区与出口时区不可合并 —— 同步生效时两者相同，关掉同步后就会分叉，都要保留
  • 不加「期望 / 实际」这类前缀（画蛇添足）

控件与按钮

  • 动作按钮一律排在状态下面，一行最多 2 个（曾因一行 3 个按钮把窗口撑宽）
  • 归位时区（默认 Asia/Shanghai）在「时区同步」里可改：关闭跟随与退出程序都写回它； 早先按「开启同步前的快照」恢复，快照会被跟随功能自己写脏（实测被写成 America/Los_Angeles），已弃用
  • 回到归位时区按钮恒定出现（不再依赖「有没有可恢复记录」），因为目标是个配置值而不是快照
  • 退出归位只在免授权助手就绪时执行 —— 否则会在退出路径上弹授权框、把退出卡住
  • 说明文字 ≤2 行，能改成键值的就不写句子
  • 状态用「键—值」两列：键 12px 灰、值 13px 常规，键列定宽保证值列对齐
  • 「维护」分区的按钮（5 个）：打开「日期与时间」设置 / 打开系统日历 / 打开运行日志 / 复制诊断信息 / 测试通知

技术约束（不改动，仅备忘）

  • 改时区走三级通道：免授权助手 → 一次性授权（原生 → AppleScript）；助手接口保持窄（只认 ping/state/set_zone/set_auto）
  • 特权写操作完成后必须独立复核（读 /etc/localtime），不信返回码
  • 开机自启用用户级 LaunchAgent（SMAppService 在 ad-hoc 签名下会 SIGTRAP 崩溃）
  • 卸载只动白名单路径，并在日志/菜单里逐条列出
  • 自测守卫 --tz-selftest（27 项，固定时间戳覆盖冬令时/夏令时），build.sh 每次构建都跑
